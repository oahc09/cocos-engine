### 关键发现

   - 阴影贴图（ResourceId::2128）正确绑定到 PS Resource Slot 0
   - CCCamera: space=0,reg=1 (CB0)
   - CCShadow: space=0,reg=2 (CB1)
   - Constants: space=1,reg=0 (CB2)

3. **阴影渲染的两个关键前置条件**：
   - 条件 (1): `cc_mainLitDir.w > 0` (CCCamera UBO offset 460)

   - 任一条件不满足 → 阴影计算完全跳过 (_1548 = 1.0)

   - 🚨 #1 (最可能): CCLocal UBO 中 `cc_localShadowBias.y = 0`
   - #2: CCCamera UBO 中 `cc_mainLitDir.w = 0`
   - #3: CCShadow UBO 中矩阵数据错误
   - #4: 阴影贴图纹理内容为空
