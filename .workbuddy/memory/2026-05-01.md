## Null Descriptor 修复 (2026-05-01 凌晨)
- **文件**: D3D12DescriptorSet.cpp forceUpdate(), D3D12Device.h/.cpp
- **问题**: null 资源绑定时跳过描述符写入，但 offset 递增 → 堆槽位零值 → D3D12 "No Resource"
- **初版修复**: 使用 `CreateShaderResourceView(nullptr, nullptr, handle)` → **失败**，导致 DEVICE_REMOVED (0x887a0005)
  - 原因: 硬件不支持 D3D12 null SRV/UAV 描述符
- **最终修复**: Dummy 资源方案（与 Vulkan 后端一致）
  - CBV: `CreateConstantBufferView(nullptr, handle)` — D3D12 规范保证支持
  - SRV(texture): 使用 Device 的 dummy 1x1 RGBA8 纹理创建真实 SRV
  - SRV(buffer): 使用 Device 的 dummy 256B buffer 创建真实 SRV
  - UAV: 使用 dummy 1x1 RGBA8 纹理创建真实 UAV
  - Sampler: 写入 default point-clamp sampler（无 GPU 资源，安全）
- **D3D12Device 新增**:
  - `getDummyTexture()` / `getDummyBuffer()` 访问器
  - doInit 中创建 1x1 RGBA8 SAMPLED|STORAGE 纹理 + 256B UNIFORM|STORAGE buffer
  - doDestroy 中释放
- **forceUpdate 中新增 3 个 lambda**:
  - `writeDummyTextureSRV` / `writeDummyBufferSRV` / `writeDummyTextureUAV`
  - 各 lambda 有 fallback: 若 dummy 资源不存在则写 null CBV
- **Release 编译通过**

## 黑屏根因定位与修复 (21:30)

### 根因：PipelineLayout 空 set 无 root parameter
- **问题**: `D3D12PipelineLayout::doInit()` 中，空 bindings 的 set layout 不创建 root parameter
- **影响**: NativePipeline 的 PER_PASS descriptor set（GLOBAL, set=0）绑定时 root parameter index = -1
- **结果**: `flushDescriptorSets()` 跳过 set=0，camera UBO (MVP 矩阵) 从未绑定到 GPU
- **表现**: VS shader 读取全零变换矩阵 → 顶点退化 → 无像素输出 → 黑屏

### 诊断过程
1. RenderDoc 确认所有 draw call 渲染到 swapchain back buffer（ResourceId::441 = back buffer index 0）
2. PSO/Shader/RTV/SRV 绑定正确，纹理数据有效
3. `d3d12-render-diag.log` 显示 `pendingSetCount=1, setIndex=1` — 只有 MATERIAL set 被 flush
4. `tryBindPassDescriptorSet()` 调用了 `bindDescriptorSet(0, ...)` 但 `graphNodeDescriptorSets` 中可能无 PER_PASS entry
5. 即使有 entry，PipelineLayout 的 root signature 中 set=0 无 root parameter → flush 跳过

### 修复方案
- **文件**: `native/cocos/renderer/gfx-d3d12/D3D12PipelineLayout.cpp`
- **改动**: 空 bindings 的 set layout 也创建一个 dummy CBV root parameter（1个 CBV range at register 0）
- **效果**: 所有 set index 都有有效的 root parameter index，bindDescriptorSet 不会跳过任何 set
- **编译**: Debug + Release 均通过
