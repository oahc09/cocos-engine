# 2026-04-26 工作日志

## Swapchain 纹理绑定修复 + Gate 2 验收

### 问题
- Release 构建运行 WebGPUDemo，进程 ~5秒后退出 (exit code 2173)
- 日志显示 "D3D12Framebuffer: color texture 0 has no D3D12 resource" 和 "depth texture has no D3D12 resource"
- 根因: `D3D12Texture::doInit(SwapchainTextureInfo)` 为空，swapchain 的颜色/深度纹理从未获得 D3D12 资源

### 修复 (5个文件)
1. **D3D12Texture.h/cpp**: 
   - 新增 `isSwapchainColorTexture()` 和 `getSwapchain()` 公共方法
   - `doInit(SwapchainTextureInfo)`: 深度纹理创建真实资源, 颜色纹理不创建（动态获取swapchain back buffer）
   - `getD3D12ResourceHandle()`: swapchain颜色纹理返回 `swapchain->getCurrentBackBufferHandle()`
   - `createResource()`: 只对swapchain颜色纹理跳过（深度纹理正常创建）

2. **D3D12Framebuffer.h/cpp**: 
   - 新增 `_swapchain` 成员和 `getSwapchain()` 方法
   - `doInit()`: 检测swapchain颜色纹理，存储swapchain指针，跳过RTV创建
   - `getRTVHandle()`: 有swapchain时动态返回 `swapchain->getCurrentRTVHandle()`

3. **D3D12CommandBuffer.cpp**: 
   - `beginRenderPass()`: 检测swapchain FBO，插入 PRESENT→RENDER_TARGET 资源屏障
   - `endRenderPass()`: 插入 RENDER_TARGET→PRESENT 反向屏障

### 验证结果
- Release 编译通过 ✅
- WebGPUDemo 进程稳定运行 85秒+ (之前5秒退出) ✅
- **Gate 2 通过**: 15秒稳定运行标准超额完成 ✅
