## D3D12 GFX PoC 崩溃修复

- **崩溃**: `PipelineSceneData::initDebugRenderer()` 第 147 行 `vector::operator[]` 越界
- **根因**: `EffectAsset::get("internal/builtin-debug-renderer")` 返回 nullptr（纯 C++ 原生启动路径中内置 effect 未被 JS 层加载注册），导致 Material::initialize 后 passes 为空 vector，直接 [0] 越界
- **修复**: 添加 passes 空检查 + 日志警告，安全降级而非崩溃
- **关联风险**: `initGeometryRenderer()` 同样依赖 `"internal/builtin-geometry-renderer"` effect，但 for-range 遍历空 vector 不会崩溃，仅功能缺失
- **编译**: Release 通过，零错误

## DebugRenderer 崩溃修复

- **崩溃**: `DebugRenderer::activate()` → `getFontPath()` → `Asset::getNativeUrl()` 空指针
- **根因**: `BuiltinResMgr::getAsset("OpenSans-Regular" 等)` 返回 nullptr，纯 C++ 原生路径中内置字体资源未加载
- **修复**: `getFontPath()` 添加 nullptr 检查返回空字符串；`activate()` 中跳过空路径字体
- **编译**: Release 通过，零错误

## Node::onBatchCreated 崩溃修复

- **崩溃**: `Node::onBatchCreated()` 第 92 行 `CC_ABORT()` 断言
- **根因**: C++ 的 `Node::onBatchCreated()` 只有 `CC_ABORT()`（注释说 "should never go here"），但 `Scene::onBatchCreated()` 递归子节点时调用了 `Node::` 版本
- **修复**: 补全 `Node::onBatchCreated()` 的 C++ 实现，参照 TS 中 node.ts 的逻辑：`invalidateChildren(TRS)` + 遍历子节点设置 siblingIndex 并递归
- **编译**: Debug/Release 均通过，WebGPUDemo Debug 稳定运行 15+ 秒

## D3D12 黑屏修复 — PSO 创建失败

- **现象**: 进程稳定运行不崩溃，但画面全黑无渲染
- **根因**: `D3D12PipelineState.cpp` 第 512 行 `if (!compiledVS || !compiledPS)` 条件阻止了第二次 fallback
  - 所有 shader 都是 GLSL 源码（非 DXBC），首次 fallback 已编译 `compiledVS`/`compiledPS`
  - 首次 PSO 创建因 InputLayout（引擎顶点属性）与 fallback shader（SV_VertexID，无顶点输入）不匹配 → E_INVALIDARG
  - 第二次 fallback（清除 InputLayout 重试）被守卫条件阻止，因为 compiledVS/compiledPS 已经非空
- **修复**: 重构 retry 逻辑，始终在首次 PSO 创建失败时清除 InputLayout 并重试，不再检查 compiledVS/compiledPS
- **验证**: Release 编译零错误；WebGPUDemo 运行 15 秒稳定，日志显示 `[PSO] Retry PSO created successfully!`，所有 draw call `pso=YES`
- **文件**: `native/cocos/renderer/gfx-d3d12/D3D12PipelineState.cpp`
