## 关键设计决策
- **双轨制**: 编辑器保持JS路径，运行时走C++快速路径
- **引用计数统一**: C++ AssetRefManager 为权威源，JS通过桥接同步
- **双层调度**: 内置组件纯C++，用户脚本通过ScriptBridge批量调用
- **二进制序列化**: 构建时 .scene JSON → .scene.bin，C++直接解析
- **用户脚本不可C++化**: 只优化桥接/调度开销，不改变JS执行本质
- **渐进式替换**: 从底层(TypeRegistry/AssetRefMgr)向上层逐步C++化

### 关键技术发现
- JSB 绑定通过 SWIG (自定义版本) 从 `.i` 文件自动生成，CMake configure 阶段执行
- `scene.i` 是核心配置文件，通过 `%ignore` 指令排除不需要绑定的方法
- `se::Value` 类型检查: `isObject()` + `toObject()->isFunction()` 替代不存在的 `isFunction()`
- `se::Object::call(se::ValueArray&, se::Object*)` 是正确的 JS 调用 API
- Node.h 原有组件管理代码全被注释，取消注释时需注意 SWIG 绑定和访问级别
- MSVC 编译成功，Clang (Win) 因版本<19 与 MSVC STL 不兼容而失败
